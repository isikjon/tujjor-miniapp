# Фаза A — Design Lab

Четыре интерактивных варианта дизайна TUJJOR на одном общем ядре. Отличается только визуальный слой
(токены, компоновка, компоненты), поэтому сравнение честное: одинаковые данные, навигация, корзина, расчёт
стоимости и интеграция с Telegram.

## Как смотреть

| Где | Адрес |
|---|---|
| Лаборатория (рекомендуется production-сборка) | `npm run lab` → http://localhost:4173/design-lab |
| Режим разработки | `npm run dev` → http://localhost:5173/design-lab |
| Вариант как отдельное мини-приложение | `/app/a`, `/app/b`, `/app/c`, `/app/d` |

В лаборатории:
- **Один вариант / Сравнение A–D** — фокус на одном телефоне с описанием или четыре телефона рядом.
- **Экраны** — 8 кнопок (Главная, Каталог, Поиск и фильтры, Карточка товара, Корзина, Оформление, Профиль, Заказы)
  синхронно переключают все видимые варианты; внутри каждого телефона всё кликабельно.
- **Тема** светлая/тёмная (как в Telegram), **язык** RU/UZ, **сеть**: быстрая / 4G / 3G / нестабильная / офлайн —
  чтобы увидеть скелетоны, повторы запросов, откат оптимистичных действий и поведение без сети.
- Шапка телефона эмулирует Telegram: «Закрыть» ↔ «Назад» (BackButton), меню ⋯, MainButton внизу, вибро-отклик
  показывается пульсом рамки. «Закрыть» перезапускает мини-приложение — корзина, черновик заказа и экран сохраняются.
- Клавиши: `1`–`4` — вариант, `C` — режим сравнения.

## Общее ядро (одинаково для всех вариантов)

- Стековая навигация: экраны под текущим остаются смонтированными (мгновенный «Назад», сохранённая прокрутка),
  анимации только `transform`/`opacity`, учёт `prefers-reduced-motion`, упрощение графики на слабых устройствах.
- Данные через TanStack Query: кеш, отмена устаревших запросов поиска, повторы с экспоненциальной задержкой и jitter,
  не более 4 одновременных запросов, предзагрузка экрана и данных товара по намерению (pointerdown).
- Изображения: AVIF → WebP → JPEG, `srcset` 240/400/640/1000, ленивая загрузка, фиксированные пропорции (без сдвигов).
- Деньги считает «сервер» (демо-API) в целых сумах; оформление заказа идемпотентно (двойное нажатие = один заказ).
- Корзина, избранное и черновик оформления переживают перезапуск; виртуализация длинных списков (TanStack Virtual).
- RU/UZ (узбекская латиница с корректными oʻ/gʻ), все суммы в UZS.

## Варианты

| | A · Premium Minimal | B · Modern Marketplace | C · Neo Commerce | D · Native Telegram |
|---|---|---|---|---|
| Идея | Монохром в духе Apple Store, товар — главный герой | Ярко и плотно, как Uzum/WB: цена, скидка и «в корзину» в каждой карточке | Дерзкий тех-ритейл: чернила + кислотный лайм, бенто, товары в свечении | Выглядит как часть Telegram: цвета темы пользователя, MainButton, сгруппированные списки |
| Шрифты | системные (0 КБ) | Onest (~50 КБ) | Unbounded (~80 КБ) | системные (0 КБ) |
| Основная кнопка | своя чёрная «пилюля» | своя фиолетовая панель + быстрое добавление с карточки | своя лаймовая кнопка с морфингом | нативная MainButton Telegram |
| Переходы | fade (спокойный) | slide (быстрый iOS) | lift (экспрессивный) | slide (iOS с параллаксом) |

## Замеры (эмуляция, production-сборка)

Chrome в эмуляции среднего Android: CPU ×4 медленнее, сеть 4G (RTT 70 мс, 9 Мбит/с), холодный кеш, 1 прогон.
Это ориентир для сравнения вариантов между собой, **не** замена профилированию на реальных Android / iOS / Telegram Desktop (фаза D).

| | A | B | C | D |
|---|---|---|---|---|
| Полезный UI (первое фото товара на главной) | 1,23 с | 1,37 с | 1,61 с | 1,21 с |
| FCP / LCP | 0,77 / 1,48 с | 0,71 / 1,64 с | 0,61 / 1,96 с | 0,56 / 1,54 с |
| Блокировка главного потока (TBT) | 75 мс | 156 мс | 165 мс | 40 мс |
| JS (сжатый, весь первый запуск) | 181 КБ | 194 КБ | 188 КБ | 194 КБ |
| Шрифты | 0 | 49 КБ | 81 КБ | 0 |
| Нажатие на товар → экран товара отрисован | 261 мс | 250 мс | 273 мс | 161 мс |

Визуальный отклик на нажатие во всех вариантах — CSS `:active` в первом кадре (< 100 мс).
Цель «холодный старт до 2,5 с на 4G» в эмуляции выполнена всеми вариантами. Известные резервы на фазы C/D:
демо-каталог сейчас грузится целиком (121 КБ gzip) — в продакшене главная получит ~10 КБ с API; vendor-чанк 123 КБ gzip
(React 19 + Router + Query) — кандидат на оптимизацию; повторное открытие с прогретым CDN-кешем ещё не измерено корректно.
Сырые данные: `docs/perf/phase-a-lab.json`.
